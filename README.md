Conjunto de paginas web para una tienda online de articulos para mascota

con logica de validacion de usuario 

logica de manejamiento de carrito desde su pagina y un dropdown desde el nav bar   
almacenamiento local para productos y usuarios 
completamente navegable a traves del navegador 

para que la version de react funcione necesita nodejs instalado 
para evitar cambios de version los modulos de node esta en el zip con el nombre, solo hay que descomprimir la carpeta en la carpeta del proyecto 
para acceder a la pagina en local en una terminal acceder a la carpeta root del proyecto y correr el comando

npm run

si ese no funciona entonces

nom run dev
